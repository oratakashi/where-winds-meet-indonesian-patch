# Honorifics & Titles

Part of [[Glossary]]. Terms of address and status titles that precede or describe an NPC —
these ARE translated, following a small set of locked mappings.

## Kinship/status terms before a name

Same pattern for all of these: translated, name itself never touched.

| English | Indonesian |
|---|---|
| Aunt | Bibi |
| Uncle | Paman |
| Grandpa | Kakek |
| Granny | Nenek |
| Elder | Tetua |
| Master (martial-arts teacher) | Guru |
| Lady / Madam / Miss | Nyonya / Nona |
| Mr. | Tuan |
| Young Master | Tuan Muda |
| Lord (noble/official title) | Tuan |

Examples: "Aunt Han" → "Bibi Han", "Elder Peng" → "Tetua Peng", "Master Wuhen" → "Guru
Wuhen", "Grandpa Zhang" → "Kakek Zhang", "Lord Wang" → "Tuan Wang", "Lord Shi" → "Tuan Shi".
*(Phase 4)*

- **"Old Man X" → "Kakek X"** (same as Grandpa). **"Old X" without "Man"** (e.g. "Old Jin")
  is kept in English because it's ambiguous whether it's a formal nickname or a description
  — revisit if the same name recurs with a clear pattern (see [[Open-Questions]]). **"Old
  Caravan Master" → "Ketua Karavan Tua"** (here "Master" = organization leader, see below).
  *(Phase 4)*

## "Master" as an organization/faction leader title

Not a personal martial-arts teacher — → **"Ketua"** (e.g. "Bloodscale Hall Master" → "Ketua
Bloodscale Hall"). "Vice Master" → "Wakil Ketua". *(Phase 4)*

Contrast with lowercase generic "master"/"Master" (a craftsman loanword, kept in English)
and "Master" as a teacher honorific (→ "Guru") — see [[Kept-In-English-Terms]] and the table
above.

## Doctor / Healer

**"Doctor" → "Tabib"** (not "Dokter") — fits the historical setting better. *(Phase 1)*

This is different from "Healer" as a tank/DPS/healer trinity role or Profession class name,
which is kept in English — see [[Kept-In-English-Terms]].

## Wayfarer / Wanderer

**"Wayfarer"/"Wanderer" → "Pengembara"** — used consistently for both English words
(including "Jianghu Wanderer" → "Pengembara Jianghu"). *(Phase 1, reconfirmed Phase 5
closing / Phase 6 opening, idx 49000–50999)*

## Generic titles/positions

- **"Chief of the Inner Court" → "Kepala Istana Dalam"**
- **"Field Commander" → "Komandan Lapangan"**

Translated consistently with the Lord→Tuan / Commander→Komandan pattern. *([[Update-1]],
batch 8)*

## Not yet locked

- **"Senior Sister"/"Junior Sister"/"Senior Brother"/"Junior Brother"** (wuxia terms of
  address between fellow disciples) are kept in English for now — no locked Indonesian
  equivalent yet (options like "Kakak/Adik Seperguruan" were considered but not decided).
  See [[Open-Questions]]. *([[Update-1]], batch 5)*
